# 制作规则

HyperCopy 支持自定义规则，让你可以为任意应用编写复制直达逻辑。本页介绍如何制作和测试规则，无需了解底层实现。

## 制作规则

在**规则管理**页面右下角点击 `+`，会弹出两个入口：

- **模拟浏览器**：自动抓取网页跳转，适合从分享链接提取 App 跳转地址
- **添加规则**：手动填写规则字段，适合已经知道目标跳转模板的场景

### 方式一：模拟浏览器抓取

适用于短链接需要经过网页跳转才能得到 App 跳转地址的情况，例如抖音、小红书的分享链接。

1. 点击 `+` → 选择「模拟浏览器」
2. 在地址栏粘贴分享链接或网页地址
3. 等待网页加载完成
4. 点击网页中的「在 App 中打开」按钮
5. 应用自动拦截 `bilibili://`、`snssdk1128://`、`intent://` 等非网页跳转
6. 页面底部展示**源网页 URL** 和**目标跳转地址**（可长按复制）
7. 点击「添加规则」，源地址和跳转信息会自动填入规则编辑页
8. 检查匹配条件并补充后保存

::: tip
模拟浏览器全程在应用内运行，不会弹出系统浏览器，适合反复抓取不同链接的跳转地址。
:::

### 方式二：手动编写

适用于你已经知道目标 App 的跳转模板，想直接填写规则的情况。

1. 点击 `+` → 选择「添加规则」
2. 填写规则字段（见下方说明）
3. 保存规则

#### 规则字段说明

| 字段 | 作用 | 示例 |
|------|------|------|
| 规则名称 | 方便识别和管理 | B站视频 |
| 执行模式 | 决定如何处理复制内容 | 见下方说明 |
| 匹配正则 | 判断复制内容是否命中本规则 | `.*bilibili\.com.*` |
| 参数正则 | 从复制内容中提取参数 | `.*\/video\/(BV[0-9A-Za-z]+).*` |
| 目标模板 | 拼接最终打开地址 | `bilibili://video/${p1}` |
| 目标包名 | 要打开的应用包名 | `tv.danmaku.bili` |

### 选择执行模式

根据复制内容的特征选择对应的处理方式：

- **解析后打开**（`parse_and_open`）：复制内容里包含 ID，需要提取后拼接到模板。例如复制 `bilibili.com/video/BV1xx`，提取 `BV1xx` 后打开 `bilibili://video/BV1xx`
- **直接打开**（`direct_open`）：目标 App 自己能识别内容，直接传给目标 App 处理。例如复制一段地址文本，直接交给高德地图搜索
- **网页解析后打开**（`webview_resolve_and_open`）：短链接必须经过网页跳转才能拿到 App 跳转地址。例如抖音 `v.douyin.com` 短链接

### 模板变量

在目标模板中可以使用以下变量替换内容：

| 变量 | 含义 |
|------|------|
| `${p1}`、`${p2}` | 参数正则提取的第 1、2 个参数 |
| `${input}` | 原始复制内容 |
| `${redirectUrl}` | 网页解析后的重定向地址（仅网页解析模式） |

### 示例规则

**B站视频**（解析后打开）

复制 `https://www.bilibili.com/video/BV1xx` → 打开哔哩哔哩 App 对应视频

- 匹配正则：`.*bilibili\.com.*`
- 参数正则：`.*\/video\/(BV[0-9A-Za-z]+).*`
- 目标模板：`bilibili://video/${p1}`
- 目标包名：`tv.danmaku.bili`

**高德地址**（直接打开）

复制包含「地址」「省」「市」的文本 → 直接用高德搜索该地址

- 匹配正则：`(?=.*(地址|省|市|镇)).{10,}`
- 目标模板：`androidamap://poi?keywords=${input}`
- 目标包名：`com.autonavi.minimap`

**抖音短链接**（网页解析后打开）

复制 `https://v.douyin.com/xxxxx` → 经网页解析后打开抖音对应视频

- 匹配正则：`.*v\.douyin\.com.*`
- 目标模板：`snssdk1128://aweme/detail/${r1}`
- 目标包名：`com.ss.android.ugc.aweme`

## 测试规则

规则保存后，可以通过以下方式验证是否生效。

### 复制触发测试

1. 复制一条测试文本或链接（例如分享一条抖音视频链接）
2. 观察 HyperCopy 是否自动识别并跳转到目标 App
3. 如果未跳转，检查匹配正则能否命中复制内容、规则开关是否已开启
4. 如果跳转目标错误，检查参数正则和目标模板的变量是否正确

### 常见问题排查

- **规则不触发**：确认规则开关已开启；检查匹配正则是否能命中复制的文本
- **跳转目标错误**：检查参数正则的捕获组顺序是否与模板变量 `${p1}`、`${p2}` 对应
- **目标 App 未打开**：确认目标包名正确，且目标 App 已安装
- **短链接无反应**：短链接需使用「网页解析后打开」模式，让应用先解析出真实跳转地址
